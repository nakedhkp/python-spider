# 微博热搜榜实时抓取器

## 项目简介
本项目为一个实时抓取微博热搜榜数据的网络爬虫，目标是获取热搜榜上的关键词、热度值（搜索量）、排名及其变化情况。适用于数据分析、社会事件监测或内容趋势分析等场景。

## 功能特性
- 实时抓取微博热搜榜信息
- 分析关键词排名、热度与变动情况
- 支持存储为本地 `.txt` 文件或 MySQL 数据库
- 模拟浏览器 Ajax 请求，绕过基础反爬机制
- 可切换移动端与PC端接口，进行对比分析

## 技术要点
- 使用浏览器开发者工具（XHR）分析微博数据接口
- 利用 `requests` 库模拟 Ajax 请求，携带必要的 Headers 和 Cookies
- 解析返回的 JSON 数据结构
- 存储为结构化数据（MySQL）或原始文本（txt）

## 依赖环境
- Python 3.7+
- requests
- pymysql（如使用 MySQL 存储）
- tqdm（可选，用于进度条）
